# ADR 0001 — TLS via stdlib rustls (Track T, option T-A)

Redis-zz codes against the `Transport` contract only, so TLS had to work
for every package with identical VM/native behavior. A C-ABI plugin
(T-B) would have split the method set and doubled parity work. T-A adds
`net.tls_connect` (+ `with_ca`/`insecure`/`tls_listen`) to the stdlib via
rustls: one shared driver, Opaque handle + staticlib FFI, zero C-tag
changes, byte-identical on both engines. Verified by `net_tls_test.zz`
strict parity + the T2 live matrix (handshake, untrusted, hostname,
plaintext-port, insecure, 1 MB blob).
